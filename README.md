# CNAS培训通知监控

基于 GitHub Actions 的 CNAS（中国合格评定国家认可委员会）官网最新通知监控系统。

## 功能

- 每天 **08:30 ~ 18:30 每小时**自动检查 CNAS 官网最新通知（共 11 次/天）
- 发现新的培训通知立即发送邮件提醒（含 PDF 原版图片 + OCR 识别文字）
- 当天无新培训通知，**末班 18:30** 发送每日总结邮件
- 执行异常时立即发送红色紧急提醒邮件
- apt 国内源加速，避免国外软件源卡顿
- 单次任务 8 分钟超时保护，防止卡死浪费时长
- 完全在 GitHub 云端运行，不依赖本地电脑

## 文件结构

```
仓库根目录/
├── .github/
│   └── workflows/
│       └── cnas_monitor.yml          # 定时任务配置（只有 yml 放这里）
├── cnas_monitor.py                    # 监控脚本
├── cnas_monitor_state.json            # 运行状态文件（自动更新，无需手动编辑）
└── README.md
```

> ⚠️ 注意：`.github/workflows/` 目录下**只放 yml 文件**，py 和 json 必须放在仓库根目录，否则脚本找不到文件。

## 部署步骤

### 1. 创建 GitHub 仓库

- 注册/登录 GitHub：https://github.com
- 新建仓库（New Repository），名称随意（如 `cnas-monitor`）
- 选择 **Public**（公开仓库完全免费，无时长限制）

### 2. 上传文件

按上面的文件结构上传：
- `cnas_monitor.py` → 仓库根目录
- `cnas_monitor_state.json` → 仓库根目录
- `cnas_monitor.yml` → `.github/workflows/` 目录下

### 3. 配置邮箱密钥

在仓库页面：

1. 点击 **Settings**（设置）
2. 左侧菜单：**Secrets and variables** → **Actions**
3. 点击 **New repository secret**，添加以下 3 个：

| 名称（Name） | 值（Secret） | 说明 |
|-------------|-------------|------|
| `SENDER_EMAIL` | `4557034@qq.com` | 发件邮箱 |
| `EMAIL_PASSWORD` | `你的QQ邮箱授权码` | 不是QQ密码，是SMTP授权码 |
| `RECEIVER_EMAIL` | `4557034@qq.com` | 收件邮箱 |

### 4. 测试运行

1. 点击仓库顶部的 **Actions** 标签
2. 左侧选择 **CNAS培训通知监控**
3. 点击 **Run workflow** → **Run workflow**（手动触发）
4. 等待 1~2 分钟，查看运行结果
5. 查收邮箱确认收到邮件

### 5. 完成

部署完成后，系统会自动按计划运行，无需人工干预。

## 监控规则

- **监控时间**：每天 08:30 ~ 18:30，每小时一次（共 11 次/天）
- **首班**：08:30
- **末班**：18:30（触发每日总结邮件）
- **新培训通知**：立即发送蓝色主题提醒邮件（含 PDF 原版截图 + OCR 文字）
- **无新通知**：末班 18:30 发送灰色主题每日总结邮件
- **执行异常**：立即发送红色主题异常提醒邮件（每次异常都发，不限制次数）

## 费用说明

- GitHub 免费版：**公开仓库完全免费，无分钟数限制**；私有仓库每月 2000 分钟
- 本脚本每次运行约 1~2 分钟（含安装 OCR 依赖时间，已用国内源加速）
- 每月约 11 次/天 × 22 工作日 × 1.5 分钟 ≈ 360 分钟
- **公开仓库不花钱；私有仓库也在免费额度内**

## 关键词筛选

通知标题包含以下关键词会被识别为培训通知：

- 培训
- 宣贯
- 学习班
- 研修班
- 讲座

## 修改配置

- **修改监控时间**：编辑 `.github/workflows/cnas_monitor.yml` 中的 cron 表达式（注意是 UTC 时间，北京时间 = UTC + 8）
- **修改末班时间**：编辑 `cnas_monitor.py` 中的 `LAST_RUN_HOUR` 和 `LAST_RUN_MINUTE`
- **修改邮箱/关键词**：编辑 `cnas_monitor.py` 中的对应配置
- **状态文件**：`cnas_monitor_state.json` 由脚本自动更新，不要手动编辑
